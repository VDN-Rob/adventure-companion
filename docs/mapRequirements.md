# Map requirements

## Functional requirements

The application should be able to:

- display a map
- display planned stops
- display the current location
- display a planned route
- work without an internet connection
- allow the user to download map data for an area
- retain downloaded map data between application launches

## Offline requirements

Once an area has been downloaded:

- the map must remain available without internet
- previously downloaded areas must remain available
- the application must not require network access to render downloaded areas

## Online requirements

Internet access may be used to:

- download map data
- update map data
- obtain other optional geographic information

## Constraints

Map data should be stored locally and should not require a permanent network connection.
